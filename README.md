# Pablo Moraga

**Transformo necesidades reales en software funcional.**

Desarrollo sistemas de IA, aplicaciones y herramientas que conectan una interfaz con funciones útiles y datos persistentes. Mi trabajo incluye sistemas que uso a diario, software entregado a otras personas y aplicaciones para procesos musicales y creativos.

En [Dasein Futures](https://www.daseinfs.com), utilizo SignalTwin para realizar simulaciones. También desarrollo mis propias herramientas para trabajar con agentes de IA y convierto necesidades concretas en productos que se pueden usar.

## En qué me enfoco

- **IA aplicada:** integrar modelos, recuperación de información, contexto estructurado y revisión en un proceso útil.
- **Datos y backend:** diseñar modelos de datos, validaciones, permisos, transiciones de estado y exportaciones.
- **Frontend:** construir interfaces para editar, revisar, configurar y completar una tarea.
- **Entrega de productos:** llevar una necesidad inicial a una aplicación que alguien pueda operar, con instrucciones y límites claros.

**Código abierto (OSS):** Soulmate, Operator Harness, Moltbook Observatory y TEXTROSS.

**Código privado:** SignalTwin, Revenue PRO, Dale Color, Spotify Playlist Builder y el descargador de videos de YouTube. Se presentan mediante casos descriptivos; su código queda fuera del paquete público.

Los casos distinguen entre software entregado, herramientas personales y trabajo que aún requiere verificación para su lanzamiento.
